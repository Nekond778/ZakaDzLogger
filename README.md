# ZakaDzLogger
KeyLogger con fines de uso educativos para ver como funciona un keylog.Es un keylogger muy basico pero funcional.
Para usarlo primero necesitas pillow que se descarga desde el cmd poniendo pip install pyinstaller pillow, tambien necesitas python 3.15 y luego simplemente descarga el .py e inicialo en tu cmd con py ZakaDzLogger.py
